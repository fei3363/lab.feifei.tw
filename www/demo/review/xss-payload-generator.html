XSS 防禦指南

🛡️ 輸入驗證

• 永遠不要信任用戶輸入

• 使用白名單驗證而非黑名單

• 限制輸入長度和格式

🔒 輸出編碼

• HTML 內容: 使用 HTML 實體編碼

• JavaScript: 使用 JavaScript 編碼

• URL: 使用 URL 編碼

• CSS: 使用 CSS 編碼

📋 Content Security Policy (CSP)

• 設定嚴格的 CSP 標頭

• 禁用 inline scripts

• 使用 nonce 或 hash
