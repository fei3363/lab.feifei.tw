🛠️ 瀏覽器開發者工具教學

學習使用 DevTools 進行網站安全測試

📂 如何開啟開發者工具

🖥️ Windows / Linux：
按 F12 或 Ctrl + Shift + I 或 Ctrl + Shift + J
🍎 macOS：
按 Cmd + Option + I 或 Cmd + Option + J
🖱️ 使用滑鼠：
在網頁上按右鍵 → 選擇「檢查」或「Inspect」
✅ 任務 1：開啟開發者工具
  • 試試不同的方法開啟開發者工具
  • 熟悉工具的位置和介面
  • 嘗試將開發者工具固定在不同位置（底部、右側、獨立視窗）

💻 Console 面板（控制台）

用途：執行 JavaScript 程式碼、查看錯誤訊息、進行除錯

基本 Console 指令

> console.log("Hello World!") Hello World! > 2 + 2 4 > document.title "開發者工具教學" > alert("測試警告") (彈出警告視窗)
✅ 任務 4：使用 Console
  • 開啟 Console 面板
  • 輸入 document.title 並按 Enter，查看網頁標題
  • 輸入 document.body.style.background = "lightblue" 改變背景色
  • 輸入 alert(document.cookie) 查看 Cookie（如果有的話）
  • 點擊上方按鈕，觀察 Console 的不同訊息類型

用途：監控所有網路請求、查看 HTTP Headers、檢查請求和回應內容

常見的請求類型

類型 說明 檔案類型
Document HTML 文件 .html
Stylesheet CSS 樣式表 .css
Script JavaScript 腳本 .js
XHR / Fetch API 請求 JSON, XML 等
Image 圖片檔案 .jpg, .png, .svg

模擬 API 請求

✅ 任務 5：監控網路請求

  • 在 Network 面板找到這個請求

📚 學習重點總結

🔹 Elements 面板

查看和修改 HTML/CSS，找出隱藏元素，分析網頁結構

🔹 Console 面板

執行 JavaScript、查看錯誤、測試程式碼片段

🔹 Network 面板

監控所有網路請求、分析 HTTP Headers、檢查 API 回應

🔹 Application 面板

管理 Cookie、LocalStorage、查看儲存的資料

🔹 Sources 面板

查看原始碼、設定中斷點、進行程式除錯

💡 資安測試小提示：
  • 使用 Elements 檢查前端驗證是否可被繞過
  • 使用 Console 測試 XSS Payload
  • 使用 Network 分析 API 請求，尋找敏感資訊
  • 使用 Application 查看是否有敏感資料存在 Cookie 或 LocalStorage
