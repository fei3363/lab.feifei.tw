🖥️ 什麼是後端？

後端（Backend）是網站或應用程式看不見的部分，負責處理資料、商業邏輯和與資料庫溝通。

前後端分工

🎨 前端 (Frontend)

職責：使用者介面
技術：HTML, CSS, JavaScript
位置：瀏覽器中執行

🔧 後端 (Backend)

職責：資料處理與邏輯
技術：PHP, Python, Node.js
位置：伺服器上執行

💾 資料庫 (Database)

職責：資料儲存
技術：MySQL, MongoDB, PostgreSQL
位置：資料庫伺服器

後端的核心功能

🔐 身份驗證

處理使用者登入、註冊、權限管理

💾 資料操作

新增、查詢、更新、刪除資料（CRUD）

🔒 安全防護

防止 SQL Injection、XSS 等攻擊

📧 外部整合

串接第三方服務、發送郵件、推播通知

📊 商業邏輯

處理複雜的計算、規則判斷

🚀 效能優化

快取、資料庫索引、負載平衡

🐘 PHP 程式語言

PHP (Hypertext Preprocessor) 是專為網頁開發設計的伺服器端腳本語言，簡單易學且功能強大。

PHP 基本語法

<?php

/*

   可以寫很多行
*/

// 變數宣告（變數名稱前要加 $）

PHP 與資料庫互動

<?php
// 連接 MySQL 資料庫
$host = "localhost";
$username = "root";
$password = "password";
$database = "mydb";

$conn = new mysqli($host, $username, $password, $database);

// 檢查連線
if ($conn->connect_error) {
    die("連線失敗: " . $conn->connect_error);
}

// 查詢資料（使用預處理語句防止 SQL Injection）
$stmt = $conn->prepare("SELECT * FROM users WHERE id = ?");
$stmt->bind_param("i", $user_id);
$user_id = 1;
$stmt->execute();
$result = $stmt->get_result();

if ($result->num_rows > 0) {
    while($row = $result->fetch_assoc()) {
        echo "姓名: " . $row["name"];
    }
}

// 新增資料
$stmt = $conn->prepare("INSERT INTO users (name, email) VALUES (?, ?)");
$stmt->bind_param("ss", $name, $email);
$name = "新使用者";
$email = "user@example.com";
$stmt->execute();

// 關閉連線
$stmt->close();
$conn->close();
?>

🔌 RESTful API 設計

API (Application Programming Interface) 讓不同系統之間可以互相溝通，REST 是目前最流行的 API 設計風格。

HTTP 方法與 CRUD 操作

GET - 讀取

取得資源，不改變伺服器狀態
範例：GET /api/users/123

POST - 新增

建立新資源
範例：POST /api/users

PUT - 更新

完整更新資源
範例：PUT /api/users/123

PATCH - 部分更新

部分更新資源
範例：PATCH /api/users/123

DELETE - 刪除

刪除資源
範例：DELETE /api/users/123

完整 PHP API 範例

<?php
// api.php - 完整的 RESTful API 範例

header("Content-Type: application/json; charset=UTF-8");
header("Access-Control-Allow-Origin: *");
header("Access-Control-Allow-Methods: GET, POST, PUT, DELETE");

// 自訂 Response Header（FLAG 可以藏在這裡！）
header("X-API-Version: 1.0");
header("X-Powered-By: KIWIS-Backend");
header("X-Secret-Message: KIWIS{B4ck3nd_");

// 取得請求方法
$method = $_SERVER['REQUEST_METHOD'];

// 解析路徑
$path = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
$path_parts = explode('/', trim($path, '/'));

// 模擬資料庫
$users = [
    1 => ["id" => 1, "name" => "張小明", "email" => "ming@example.com"],
    2 => ["id" => 2, "name" => "李大華", "email" => "hua@example.com"],
    3 => ["id" => 3, "name" => "王美麗", "email" => "mei@example.com"]
];

// 路由處理
switch ($method) {
    case 'GET':
        if (isset($path_parts[2]) && $path_parts[1] == 'api' && $path_parts[2] == 'users') {
            // GET /api/users - 取得所有使用者
            if (isset($path_parts[3])) {
                // GET /api/users/{id} - 取得單一使用者
                $id = intval($path_parts[3]);
                if (isset($users[$id])) {
                    echo json_encode([
                        "success" => true,
                        "data" => $users[$id],
                        // FLAG 片段藏在這裡
                        "_metadata" => [
                            "timestamp" => time(),
                            "hint" => "檢查 Response Headers",
                            "secret" => base64_encode("4P1_M45t3r}")
                        ]
                    ], JSON_UNESCAPED_UNICODE);
                }
            }
        }
        break;
}
?>

🔍 FLAG 藏在哪裡？

提示 1：檢查 HTTP Response Headers 中的自訂標頭（X- 開頭的）

提示 2：某個 API 回應的 JSON 中有 Base64 編碼的秘密

提示 3：試著呼叫 /flag 這個隱藏的 endpoint

📨 API 回應

等待 API 呼叫... 💡 重要提示： 1. 按下 F12 開啟開發者工具 2. 切換到「Network（網路）」分頁 3. 點擊上方按鈕呼叫 API 4. 在 Network 中點擊該請求 5. 查看「Headers」區域找出 X-Secret-Message 6. 查看「Response」區域找出 _metadata.secret

🎓 如何找到 FLAG？

  1. 按下 F12 開啟開發者工具
  2. 切換到「Network（網路）」分頁
  3. 點擊上方「取得特定使用者」按鈕呼叫 API
  4. 在 Network 分頁中點擊該請求（api.php）
  5. 查看「Headers（標頭）」→「Response Headers」
  6. 找出 X-Secret-Message 標頭（FLAG 第一部分）
  7. 切換到「Response」或「Preview」分頁
  8. 找到 _metadata.secret 欄位
  9. 這是 Base64 編碼，在 Console 輸入：atob('編碼內容')
  10. 組合兩個片段得到完整 FLAG！
