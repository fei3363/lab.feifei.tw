📄 HTML - 超文本標記語言

HTML (HyperText Markup Language) 是網頁的骨架，定義網頁的結構和內容。

什麼是 HTML？

HTML 使用「標籤」(Tags) 來標記不同類型的內容。每個標籤都有特定的意義和功能，瀏覽器會根據這些標籤來呈現網頁。

🏗️ 結構化

使用語意化標籤組織內容，讓網頁結構清晰

🔗 超連結

透過連結將不同頁面串連，形成網路

📱 跨平台

在各種裝置和瀏覽器上都能正常顯示

♿ 無障礙

支援螢幕閱讀器，讓所有人都能使用

基本 HTML 結構

<!DOCTYPE html>
<html lang="zh-TW">
<head>
    <meta charset="UTF-8">
    <title>我的第一個網頁</title>
</head>
<body>
    <!-- 這是 HTML 註解，瀏覽器不會顯示 -->
    <h1>歡迎來到我的網站</h1>
    <p>這是一個段落。</p>
</body>
</html>

常用 HTML 標籤

<!-- 標題標籤 (h1 到 h6) -->
<h1>最大的標題</h1>
<h2>次標題</h2>

<!-- 段落和文字格式 -->
<p>這是一個段落</p>
<strong>粗體文字</strong>
<em>斜體文字</em>

<!-- 清單 -->
<ul>
    <li>無序清單項目 1</li>
    <li>無序清單項目 2</li>
</ul>

<!-- 連結和圖片 -->
<a href="https://example.com">這是一個連結</a>
<img src="image.jpg" alt="圖片描述">

<!-- 表單元素 -->
<form>
    <input type="text" placeholder="輸入文字">
    <button type="submit">送出</button>
</form>

🎨 CSS - 階層式樣式表

CSS (Cascading Style Sheets) 負責網頁的外觀和排版，讓網頁變得美觀。

CSS 的作用

CSS 可以控制顏色、字型、間距、版面配置、動畫等所有視覺效果。

🎨 美化介面

設定顏色、字型、邊框等樣式

📐 版面配置

使用 Flexbox、Grid 排列元素

✨ 動畫效果

建立過渡效果和關鍵影格動畫

📱 響應式設計

透過媒體查詢適應不同螢幕

CSS 選擇器

/* 元素選擇器 */
p {
    color: blue;
}

/* 類別選擇器 */
.my-class {
    font-size: 18px;
}

/* ID 選擇器 */
#my-id {
    background-color: yellow;
}

/* 組合選擇器 */
div p {
    margin: 10px;
}

/* 偽類選擇器 */
a:hover {
    color: red;
}

常用 CSS 屬性

/* 文字樣式 */
.text-style {
    color: #333;              /* 文字顏色 */
    font-size: 16px;          /* 字體大小 */
    font-weight: bold;        /* 字體粗細 */
    text-align: center;       /* 文字對齊 */
}

/* 盒子模型 */
.box-model {
    width: 200px;             /* 寬度 */
    height: 100px;            /* 高度 */
    padding: 20px;            /* 內距 */
    margin: 10px;             /* 外距 */
    border: 2px solid black;  /* 邊框 */
}

/* 背景和裝飾 */
.decoration {
    background-color: lightblue;
    border-radius: 10px;      /* 圓角 */
    box-shadow: 0 4px 6px rgba(0,0,0,0.1);
}

/* Flexbox 排版 */
.flex-container {
    display: flex;
    justify-content: center;
    align-items: center;
}

完整範例：計數器

<!DOCTYPE html>
<html>
<head>
    <style>
        /* CSS: 美化計數器 */
        .counter {
            text-align: center;
            padding: 30px;
            background: linear-gradient(135deg, #f5d652, #cfe867);
            border-radius: 15px;
        }
        .count {
            font-size: 3em;
            font-weight: bold;
            margin: 20px 0;
        }
        button {
            padding: 10px 20px;
            margin: 5px;
            font-size: 1.1em;
            border: none;
            border-radius: 8px;
            cursor: pointer;
        }
    </style>
</head>
<body>
    <!-- HTML: 定義結構 -->
    <div class="counter">
        <h2>計數器</h2>
        <div class="count" id="count">0</div>
        <button onclick="increment()">增加</button>
        <button onclick="decrement()">減少</button>
        <button onclick="reset()">重設</button>
    </div>

    <script>
        // JavaScript: 實作功能
        let count = 0;
        
        function increment() {
            count++;
            updateDisplay();
        }
        
        function decrement() {
            count--;
            updateDisplay();
        }
        
        function reset() {
            count = 0;
            updateDisplay();
        }
        
        function updateDisplay() {
            document.getElementById('count').textContent = count;
        }
    </script>
</body>
</html>

前後端分工

前端 (Frontend):
├── HTML: 網頁結構
├── CSS: 視覺設計
└── JavaScript: 使用者互動

後端 (Backend):
├── 伺服器程式: Node.js, Python, Java, PHP
├── 資料庫: MySQL, MongoDB, PostgreSQL
├── API: 提供資料給前端
└── 商業邏輯: 處理核心功能

前後端溝通:
└── HTTP/HTTPS: 使用 AJAX、Fetch API 交換資料
