💡 什麼是 UNION SELECT？

UNION 是 SQL 的關鍵字，用來合併兩個查詢的結果。

攻擊者可以利用 UNION 來查詢其他資料表的資料，例如：

  • 📊 取得使用者帳號密碼
  • 🔐 讀取管理員資料
  • 💳 竊取信用卡資訊
  • 🗂️ 探測資料庫結構

📚 UNION 基本概念

🔍 UNION 的運作方式

UNION 可以把兩個查詢的結果合併成一個結果集：

查詢 1：商品資料
SELECT name, price FROM products WHERE id = 1

name price
筆記型電腦 25000
⬇️ UNION ⬇️
查詢 2：使用者資料（攻擊者注入的）
SELECT username, password FROM users WHERE id = 1

username password
admin secret123
⬇️
合併後的結果
欄位 1 欄位 2
筆記型電腦 25000
admin secret123

⚠️ 攻擊者成功取得管理員密碼！

⚠️ UNION 的限制

使用 UNION 有一個重要條件：

兩個查詢必須有相同數量的欄位！

例如：第一個查詢有 3 個欄位，第二個查詢也必須有 3 個欄位。

🔍 步驟 1：使用 ORDER BY 探測欄位數量

💡 為什麼需要知道欄位數量？

因為 UNION 要求兩邊的查詢有相同的欄位數量。

攻擊者通常不知道原始查詢有幾個欄位，所以要先「探測」。

🎯 探測方法：ORDER BY

ORDER BY 可以按照欄位編號排序。

如果編號超過欄位數量，就會產生錯誤！

攻擊者可以用這個方法找出正確的欄位數量。

🧪 實驗：探測欄位數量

點擊測試按鈕查看 SQL 指令
測試結果會顯示在這裡

✅ 探測結果

當 ORDER BY 4 成功，但 ORDER BY 5 失敗時，表示查詢有 4 個欄位！

現在我們知道要用 UNION SELECT 配合 4 個欄位。

🎯 步驟 2：使用 UNION SELECT NULL

💡 為什麼使用 NULL？

因為 NULL 可以匹配任何資料型別！

先用 NULL 測試 UNION 是否成功，再逐步替換成我們想要的資料。

🧪 實驗：UNION SELECT NULL

✅ UNION 成功！

當欄位數量正確時，UNION SELECT NULL 會成功執行！

現在我們可以開始注入真正的資料查詢了。

💡 information_schema 是什麼？

information_schema 是 MySQL 的系統資料庫，儲存了所有資料庫的結構資訊。

攻擊者可以從這裡取得：

  • 所有資料表名稱
  • 所有欄位名稱
  • 資料庫版本
  • 權限資訊

✅ 如何防禦 UNION SELECT 注入？

1. 使用 Prepared Statement（最重要！）

// 不安全 ❌
$sql = "SELECT * FROM products WHERE id = " . $_GET['id'];

// 安全 ✅
$stmt = $pdo->prepare("SELECT * FROM products WHERE id = ?");
$stmt->execute([$_GET['id']]);

2. 限制資料庫權限

  • 不要用 root 帳號連接資料庫
  • 限制只能存取必要的資料表
  • 禁止存取 information_schema

3. 錯誤訊息處理

  • 不要顯示詳細的 SQL 錯誤訊息給使用者
  • 記錄錯誤到日誌檔案，不要輸出到網頁

4. 輸入驗證

  • 檢查參數是否為預期的資料型別
  • 使用白名單過濾
