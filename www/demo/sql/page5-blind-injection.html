💡 什麼是盲注？

盲注 (Blind SQL Injection) 是指在看不到任何錯誤訊息或查詢結果的情況下，仍然能夠竊取資料的攻擊手法。

這種情況發生在：

  • ❌ 網站不顯示 SQL 錯誤訊息
  • ❌ 查詢結果不會顯示在頁面上
  • ❌ 無法使用 UNION SELECT

但攻擊者仍然可以透過頁面的細微變化來推測資料！

📚 盲注的兩種類型

🔵 布林盲注
(Boolean-based)

觀察頁面內容的變化
• 條件為真 → 顯示商品
• 條件為假 → 不顯示商品
⏱️ 時間盲注
(Time-based)

觀察回應時間的變化
• 條件為真 → 延遲 5 秒
• 條件為假 → 立即回應

🔵 類型 1：布林盲注 (Boolean-based Blind SQL Injection)

💡 原理說明

攻擊者透過觀察頁面內容的有無來判斷條件的真假。

就像玩「猜數字遊戲」，每次只能問「是或否」的問題，逐步縮小範圍。

🎯 攻擊情境

假設有一個商品查詢頁面：product.php?id=1

• 正確的 ID → 顯示商品資訊

• 錯誤的 ID → 顯示「找不到商品」

攻擊者可以利用這個「有或無」的差異來推測資料！

🧪 實驗：布林盲注測試

點擊測試按鈕查看 SQL 指令
測試結果會顯示在這裡

✅ 發現盲注漏洞！

觀察到：

  • 1 AND 1=1 → 顯示商品（條件為真）
  • 1 AND 1=2 → 不顯示商品（條件為假）

這表示我們可以透過構造條件來「問問題」，系統會用「有或無」來回答！

🔍 布林盲注：逐字元探測管理員密碼

🚨 攻擊目標

假設我們想知道管理員（admin）的密碼是什麼。

我們可以逐字元地問系統：

  • 「密碼的第一個字元是 a 嗎？」
  • 「密碼的第一個字元是 b 嗎？」
  • 「密碼的第一個字元是 s 嗎？」✓ （找到了！）

💡 使用的 SQL 函數

SUBSTRING(字串, 位置, 長度) - 取出字串的一部分

ASCII(字元) - 取得字元的 ASCII 碼

範例：SUBSTRING((SELECT password FROM users WHERE username='admin'), 1, 1)

→ 取出 admin 密碼的第 1 個字元

⏱️ 類型 2：時間盲注 (Time-based Blind SQL Injection)

💡 原理說明

當頁面內容完全沒有變化時，攻擊者可以改為觀察回應時間。

使用 SLEEP() 函數來製造延遲：

  • 條件為真 → 延遲 5 秒後回應
  • 條件為假 → 立即回應

🎯 攻擊情境

即使頁面完全沒有任何變化，攻擊者仍可透過延遲來竊取資料。

就像在黑暗中，透過「等待時間」來傳遞訊息。

🧪 實驗：時間盲注測試

點擊測試按鈕查看 SQL 指令
⏳
查詢執行中...
0 秒
測試結果會顯示在這裡

💡 時間盲注的實際應用

攻擊者可以用類似布林盲注的方式逐字元探測：

-- 如果密碼第一個字元是 's'，延遲 5 秒
1 AND IF(
    SUBSTRING((SELECT password FROM users WHERE username='admin'), 1, 1) = 's',
    SLEEP(5),
    0
)

📊 盲注類型比較

特性 布林盲注 時間盲注
判斷依據 頁面內容有無變化 回應時間長短
速度 較快 較慢（需要等待延遲）
可靠性 高 中（可能受網路影響）
適用情境 頁面內容會變化 頁面內容完全不變
使用函數 SUBSTRING, ASCII SLEEP, BENCHMARK
容易被偵測 較難 較易（異常延遲）

🤖 自動化盲注攻擊

⚠️ 實際攻擊中的自動化

手動一個字元一個字元測試太慢了！攻擊者通常會使用自動化工具：

  • SQLMap - 最知名的 SQL Injection 自動化工具
  • 自製腳本 - 用 Python, JavaScript 等撰寫

💡 自動化攻擊流程

  1. 確定字串長度（用 LENGTH() 函數）
  2. 對每個位置進行二分搜尋（Binary Search）
  3. 逐字元確定每個字元的 ASCII 碼
  4. 組合成完整的密碼
Python 自動化範例（概念）： 
import requests

password = ""
for position in range(1, 20):
    for char in 'abcdefghijklmnopqrstuvwxyz0123456789':
        payload = f"1 AND SUBSTRING((SELECT password FROM users), {position}, 1)='{char}'"
        response = requests.get(f"http://target.com/product?id={payload}")

        if "商品名稱" in response.text:
            password += char
            print(f"找到第 {position} 個字元: {char}")
            break

print(f"密碼是: {password}")

✅ 如何防禦盲注攻擊？

1. 使用 Prepared Statement（最重要！）

// 參數化查詢可以防止所有類型的 SQL Injection
$stmt = $pdo->prepare("SELECT * FROM products WHERE id = ?");
$stmt->execute([$_GET['id']]);

2. WAF (Web Application Firewall)

  • 偵測異常的查詢模式
  • 阻擋包含 SLEEP、BENCHMARK 等危險函數的請求
  • 限制單一 IP 的請求頻率

3. 監控與警報

  • 記錄異常慢的查詢
  • 偵測大量相似的請求
  • 追蹤可疑的 IP 位址

4. 最小權限原則

  • 資料庫帳號只給必要的權限
  • 不同功能使用不同的資料庫帳號
