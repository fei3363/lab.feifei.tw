🗄️ 步驟 0：建立資料庫與資料表

💡 什麼是資料庫與資料表？

資料庫 (Database)：用來儲存資料的容器，就像一個大檔案櫃

資料表 (Table)：資料庫中的表格，用來組織和儲存具體的資料

1. 建立資料庫

點擊「建立資料庫」按鈕查看 SQL 指令

2. 建立資料表

資料表需要定義欄位（欄位名稱和資料型別）

常見的資料型別：

  • INT - 整數
  • VARCHAR(長度) - 文字
  • TEXT - 長文字
  • DATE - 日期
點擊「建立 users 資料表」按鈕查看 SQL 指令

📝 CREATE TABLE 指令說明

CREATE TABLE 用來建立新的資料表。

語法：

CREATE TABLE 資料表名稱 (
    欄位1 資料型別 [約束],
    欄位2 資料型別 [約束],
    ...
)

常見約束：

  • PRIMARY KEY - 主鍵（唯一識別）
  • AUTO_INCREMENT - 自動遞增
  • NOT NULL - 不可為空
